================================================================================
                    KABIPAY - QUICK START GUIDE
================================================================================

🎯 GET STARTED IN 3 STEPS:

Step 1: Install Dependencies
-----------------------------
Open PowerShell in the KabiPay-UI folder and run:

    cd d:\work\KabiPay-UI
    npm install

This will install all required packages (React, TypeScript, Tailwind, etc.)


Step 2: Start Development Server
---------------------------------
After installation completes, run:

    npm run dev

The server will start and show you a URL (usually http://localhost:5173)


Step 3: Open in Browser
------------------------
Open your browser and go to:

    http://localhost:5173

You should see the KabiPay application login/dashboard!

================================================================================
                              TROUBLESHOOTING
================================================================================

❌ If "npm install" fails:
    - Check Node.js version (need v18+): node --version
    - Delete node_modules folder and try again
    - Try: npm cache clean --force

❌ If dev server won't start:
    - Check if port 5173 is already in use
    - Try a different port: npm run dev -- --port 3000

❌ If you see "command not found":
    - Make sure you're in the KabiPay-UI folder
    - Check Node.js is installed: node --version
    - Check npm is installed: npm --version

❌ If browser shows blank page:
    - Check console for errors (F12 in browser)
    - Clear browser cache and refresh
    - Try a different browser
